# 🏆 랭커의 쇼핑 (Ranker's Shopping) - 8대 쇼핑몰 실시간 랭킹 포털

본 프로젝트는 **구글 애드센스(Google AdSense) 승인 심사를 완벽히 통과하고, 8대 쇼핑몰 실시간 랭킹 큐레이션 및 20~70대 연령별 랭킹 센터를 통해 지속적인 방문자와 제휴 수익을 창출할 수 있도록** 기획·설계된 전문 쇼핑 포털 & 정보성 매거진 웹사이트입니다.

## 🎯 구글 애드센스 심사 통과를 위한 핵심 전략

### 1단계: 심사 기간 (현재 상태 그대로 제출)
- **외부 쇼핑 링크(쿠팡파트너스 등)를 아직 넣지 마세요!**
  - 구글 심사관이나 AI 로봇이 사이트를 검토할 때 제휴 마케팅 링크가 많으면 "가치 없는 콘텐츠(Thin Content)"로 판단하여 거절합니다.
  - 현재 사이트에 포함된 5편의 글은 **완성형 전문 정보성 콘텐츠**이므로, 이 상태 그대로 신청하시면 심사 통과 확률이 매우 높습니다.

### 2단계: 승인 완료 후 (수익 극대화)
- 애드센스 승인 메일을 받은 후:
  1. 각 아티클의 제품 추천 섹션에 쿠팡파트너스나 스마트스토어 제휴 링크를 자연스럽게 삽입합니다.
  2. `terms.html`에 이미 **"제3조 제휴 마케팅 공지(Affiliate Disclosure)"**가 합법적으로 기재되어 있으므로 안심하고 수익 활동을 병행하실 수 있습니다.
  3. **구글 애드센스 광고 수익 + 쇼핑 제휴 커미션 수익**의 더블 파이프라인이 완성됩니다.

## 🌐 무료 웹 배포 방법 (3분 완성)

구글 애드센스는 개인 도메인(예: `mysite.com`, `mysite.co.kr` 등)을 연결하는 것을 가장 권장합니다.

### 방법 1. Cloudflare Pages (무료 호스팅 + 도메인 연결 추천)
1. [Cloudflare](https://dash.cloudflare.com/)에 회원가입합니다.
2. [Workers 및 Pages] > [Pages] > [직접 업로드(Direct Upload)] 선택.
3. 이 `만들기` 폴더 안의 모든 파일과 폴더를 통째로 드래그 앤 드롭하여 업로드합니다.
4. 배포가 완료되면 `https://프로젝트명.pages.dev` 무료 주소가 즉시 생성됩니다.
5. 보유하신 개인 도메인이 있다면 [Custom Domains] 탭에서 클릭 한 번으로 연결할 수 있습니다.

### 방법 2. GitHub Pages
1. GitHub 저장소(Repository)를 만들고 이 폴더의 파일들을 커밋/푸시합니다.
2. [Settings] > [Pages]에서 브랜치를 `main`으로 지정하면 무료로 사이트가 열립니다.

## 📝 구글 애드센스 신청 절차 (보내주신 스크린샷 화면 기준)

1. **애드센스 사이트 등록**:
   - 애드센스 [사이트] 메뉴에서 **[+ 새 사이트]** 클릭.
   - 준비된 본인의 도메인 주소(예: `https://smartlifelab.kr`) 입력 후 저장.
2. **애드센스 코드 삽입**:
   - 구글에서 제공하는 `<script async src="https://pagead2.googlesyndication.com/..."></script>` 코드를 복사합니다.
   - `index.html`, `about.html`, `contact.html`, `privacy.html`, `terms.html`, 그리고 `articles/*.html` 파일의 `<head>` 태그 안 주석 위치에 붙여넣습니다.
3. **ads.txt 수정**:
   - `ads.txt` 파일의 `pub-0000000000000000` 부분을 본인의 애드센스 게시자 ID로 변경합니다.
4. **검토 요청**:
   - 애드센스 사이트 화면에서 "코드 삽입 완료" 체크 후 **[검토 요청]** 버튼을 누릅니다.
   - 보통 2일 ~ 1주일 이내에 승인 완료 메일이 도착합니다.

## 🛠️ 사이트 운영 & 커스텀 가이드 (공지/주간베스트/새 글)

### 1. 상단 공지사항 바 문구 및 링크 변경하기
- `index.html` 파일을 메모장이나 VS Code로 엽니다.
- `<!-- [운영자 공지사항 바] -->` 주석 아래의 `<span>` 텍스트와 `<a href="...">` 링크를 원하는 공지 내용이나 새 글 주소로 바꾸면 즉시 홈 화면 상단에 반영됩니다.

### 2. '주간 베스트 가이드 (1위/2위/3위)' 직접 선정하기
- `index.html` 내 `<!-- [🏆 운영자 직접 선정: 주간 베스트 & 에디터 초이스] -->` 섹션을 찾습니다.
- `<div class="rank-badge rank-1">1</div>` 아래의 제목, 설명, 링크를 이번 주에 가장 추천하고 싶은 글로 자유롭게 변경하시면 됩니다.

### 3. 새로운 블로그 글 작성 및 홈에 등록하기
1. `articles/` 폴더 안의 아무 html 파일(예: `smartphone-battery.html`)을 복사하여 새 이름(예: `my-new-post.html`)으로 만듭니다.
2. 제목과 본문 내용을 원하는 주제로 작성합니다.
3. `index.html`의 `<!-- [💡 새로운 블로그 글 추가 팁] -->` 주석 바로 아래에 기존 아티클 카드(`<article class="article-card">...</article>`)를 복사해 새 글 링크와 제목을 넣으면 홈 화면 아티클 목록에 즉시 노출됩니다.

### 4. ⚡ 원클릭 쇼핑 특가 퀵 허브 배너 링크 교체하기 (수익화)
- `index.html` 내 `<!-- [⚡ 고객 선호도 1위: 8대 쇼핑몰 공식 특가 퀵 허브] -->` 영역을 찾습니다.
- 현재는 **네이버쇼핑(국민 1위 강조), 쿠팡, 11번가, SSG.COM 신세계몰, 아마존, 알리익스프레스, 오늘의집 리빙, G마켓** 8대 공식 주소가 연결되어 있습니다.
- **애드센스 승인 완료 후**: `js/main.js` 상단의 `AFFILIATE_CONFIG`에 본인의 **제휴 마케팅 코드**(쿠팡 파트너스, 알리 어필리에이트, 아마존 어소시에이트 등)를 입력하시거나, 각 링크를 제휴 링크로 교체하시면 방문자가 배너를 누르고 구매할 때마다 수수료 수익이 자동으로 발생합니다!

### 5. 🔴 매일 자동 갱신되는 구글 뉴스 & 3초 스마트 가전 진단기
- 사용자가 접속할 때마다 자바스크립트(`js/main.js`)가 오늘 날짜 기준 최신 테크 뉴스를 실시간으로 호출하여 브리핑 카드로 자동 렌더링합니다.
- 방문자는 3초 스마트 가전 진단기를 통해 자신의 주거 환경과 예산에 딱 맞는 제품을 직접 시뮬레이션할 수 있어 사이트 체류 시간이 대폭 증가합니다.
